## Running benchmarks

Clone the source repo and use the benchmark stack:

```bash
git clone https://github.com/tributary-gateway/tributary-benchmarks.git
cd tributary-benchmarks
docker compose -f docker-compose.bench.yml up
./run-all.sh
```

## What we measure

- **Streaming latency** — time from first byte sent to first byte received
- **Throughput** — concurrent requests sustained without errors
- **Memory** — RSS under load
- **Cold start** — time from process start to first request served
